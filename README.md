`Python` `Flask` `SQLite` `Docker` `HTML/CSS`

**[Multi-Domain-Support-Triage-Agent](https://github.com/vinod-meghwar/Multi-Domain-Support-Triage-Agent)**
An AI-powered support ticket triage agent built for the HackerRank Orchestrate Hackathon. Classifies and routes support tickets across multiple domains using Python and LLM integration.
